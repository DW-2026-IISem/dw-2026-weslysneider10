# ISS-11 — Catálogo de errores

## 1. Errores de compilación Angular

Registrar:
- Código del error.
- Archivo afectado.
- Línea del error.
- Causa.
- Solución aplicada.
- Resultado de la nueva compilación.

## 2. Errores de PrimeNG

Registrar:
- Componente afectado.
- Mensaje de error.
- Importación requerida.
- Solución aplicada.

## 3. Errores de autenticación

Registrar:
- Código HTTP.
- Ruta afectada.
- Comportamiento del interceptor.
- Resultado de la autenticación.

## 4. Errores de comunicación

Registrar:
- Problemas de CORS.
- Errores de conexión.
- Dirección de la API.
- Puerto utilizado.

## 5. Errores de pruebas

Registrar:
- Prueba afectada.
- Resultado esperado.
- Resultado obtenido.
- Corrección aplicada.
